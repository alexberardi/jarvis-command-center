Tool: control_device
Description: Control a Home Assistant device: open/close covers, lock/unlock doors, adjust thermostat, etc.
Parameters:
  - entity_id (string) [REQUIRED]: Home Assistant entity ID (e.g., 'cover.garage_door', 'lock.front_door', 'climate.thermostat'). Find in device_controls context.
  - action (string): Action to perform. Domain-specific: covers use open_cover/close_cover/stop_cover, locks use lock/unlock, climate uses set_temperature/set_hvac_mode/turn_on/turn_off. If unsure, omit and system will ask.
  - value (string): Value for set actions (e.g., temperature '72' for climate, percentage '50' for fans). Only needed for set_* actions.


Tool: control_music

  - player (string): Target speaker. If not specified, controls current/default player.

Description: Convert units for distance, volume, weight/mass, and temperature.

  - to_unit (string) [REQUIRED]: Target unit name (e.g., 'kilometers', 'liters', 'kilograms', 'fahrenheit').
  - category (string): Optional hint: 'distance', 'volume', 'weight', or 'temperature'.
